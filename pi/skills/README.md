# pi skills

markdown-based skill files for the pi coding agent.

each skill is a directory with SKILL.md inside.
skills teach pi domain-specific workflows.

## skills

- `ask-deepwiki-answer/` answer a question about a public repository from its DeepWiki.
- `autonomy-protocol/` compose, format, and lint `.playbook` work protocols.
- `communication-standard/` guide two-party communication toward a shared decision.
- `fetch-deepseek-share/` fetch a DeepSeek shared conversation as raw JSON.
- `rule-writing/` compose, review, and lint a rule set shared by agent and human.

## references and scripts

skills may carry `references/`, `assets/`, and `scripts/` next to SKILL.md.
paths in SKILL.md are relative to the skill directory.

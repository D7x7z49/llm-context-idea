FORM
- [ ] the universe is named
- [ ] the target set is finite and enumerable
- [ ] the forbidden set is derived as the complement
- [ ] a negation carries an identified positive target or is [pending]

CONTENT
- [ ] one concept per rule
- [ ] the concept survives a change of file structure
- [ ] a state, an example, and an instance stay outside the rule
- [ ] the rule is an imperative sentence in simple words
- [ ] an abbreviation is expanded at its first occurrence

LAYOUT
- [ ] one item on one line
- [ ] every line ends at `,` or `.`
- [ ] every structural character is in the symbol set
- [ ] every structural character is reachable from a mainstream input method
- [ ] every level is paired, every sibling is joined
- [ ] rule text holds no heading and no colon

BUDGET
- [ ] the section count is within seven plus or minus two
- [ ] the item count per section is within seven plus or minus two
- [ ] the file line count is within sixty four
- [ ] the lint script reports no error

HANDOVER
- [ ] a peer can restate the rule without the rule file

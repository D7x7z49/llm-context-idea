BOUNDARY
- give every structure a paired start and end
- nest a level with paired delimiters
- join siblings with `,` or a block separator
- prefer a closed boundary over a shorter open form
- expect an unpaired connector to carry no boundary

SYMBOL SET
- treat the set as a whitelist
- map one shape to one meaning
- keep the set small, so a peer can hold it
- add a shape only with a stated need

REACHABLE KEY
- admit a structural character only when a mainstream input method types it directly
- expect a layout dependent glyph to vanish across environments
- express a relation with a short word when no shape fits
- express a time or a key with a pair of delimiters and `,`

LINE FORM
- put one item on one line
- end a line at `,` or `.`
- write body text in lowercase, uppercase for a term and a marker
- open a code block with a typed fence
- expand an abbreviation at its first occurrence

ATTENTION BUDGET
- keep one message or one list within seven plus or minus two units
- keep the rule set within seven plus or minus two sections
- keep the rule file within sixty four lines
- split the content when the count is exceeded
- apply the budget to the rule set itself
